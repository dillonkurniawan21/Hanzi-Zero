# Hanzi Zero 🏮

**Hanzi Zero** is a premium HSK Chinese learning application designed for a modern, high-end educational experience. It features a centralized learning path, intelligent progress tracking, and a sleek "Kinetic Scholar" aesthetic.

## ✨ Key Features

- **Progressive Learning Path**: A structured journey through HSK levels with interactive lesson nodes.
- **Interactive Quizzes**: Dynamic exercises including writing practice, character matching, and listening tests.
- **AI-Powered Analysis**: Neural network-based performance analysis to identify weaknesses and recommend targeted lessons.
- **Secure Authentication**: Protected login system with localized user persistence.
- **Premium Design**: Dark-mode optimized UI with smooth animations, glassmorphism, and custom Disney-style dragon mascot branding.
- **Responsive Layout**: Optimized for both desktop sidebar and mobile bottom navigation.

## 🚀 Technology Stack

- **Frontend**: HTML5, CSS3 (Vanilla), JavaScript (ES6+)
- **Backend**: Python (Flask)
- **Deployment**: Vercel
- **Libraries**: 
  - `hanzi-writer` for stroke-by-stroke character animations.
  - `TensorFlow.js` (inference) for learning analytics.
  - Google Fonts (Outfit, Ma Shan Zheng).

## 🔒 Security Updates

- **AI Chat Update**: As of May 2026, AI chat functionality has been pivoted to local/mock responses to enhance API security.
- **Auth Hardening**: Implemented secure authentication flows with branding consistency.
